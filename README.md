## 🌐 Deploy on GitHub Pages

### Step 1 — Create Repository
1. Go to [github.com/new](https://github.com/new)
2. Name it `portfolio` (or any name you like)
3. Set it to **Public**
4. Click **Create repository**

### Step 2 — Upload Files
**Option A — Drag and Drop (easiest):**
1. Open your new repository on GitHub
2. Click **"uploading an existing file"**
3. Drag all 4 files (`index.html`, `resume.html`, `style.css`, `main.js`) into the box
4. Click **Commit changes**

**Option B — Git CLI:**
```bash
git init
git add .
git commit -m "Initial portfolio commit"
git branch -M main
git remote add origin https://github.com/Maneeshy440/portfolio.git
git push -u origin main
```

### Step 3 — Enable GitHub Pages
1. Go to your repository → **Settings** → **Pages**
2. Under **Source**, select `main` branch and `/ (root)` folder
3. Click **Save**
4. Your site will be live at `https://maneeshy440.github.io/portfolio` within 1–2 minutes ✅
